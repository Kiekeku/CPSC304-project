# Backend (FastAPI + Python)

## Required env vars
- `ORACLE_USER`
- `ORACLE_PASS`
- `ORACLE_HOST`
- `ORACLE_PORT`
- `ORACLE_DBNAME`
- `PORT`

## Structure
- `main.py`: app startup file
- `routers/`: API routes
- `services/`: DB
- `models/schemas.py`: request models
- `sql/`: schema and seed SQL files
